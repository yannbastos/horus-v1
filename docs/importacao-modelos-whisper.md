# Importação explícita de modelos Whisper locais

O Hórus não baixa modelos automaticamente. A API autenticada permite importar uma pasta faster-whisper já obtida pelo operador, listar os cinco modelos suportados e remover apenas instalações gerenciadas pelo importador. A interface de prontidão ainda não usa essas rotas; este incremento fornece o contrato para integração posterior.

- `GET /v1/transcription/models`: catálogo com `model`, `installed`, `managed`, `size_bytes`, `license`, `source` e `removable`. `source` contém apenas tipo e nome da pasta, sem seu caminho completo; é nulo para modelos de legado. `installed` indica presença dos arquivos, não validação por inferência.
- `POST /v1/transcription/models/import`: corpo `{ "model": "small", "source_directory": "C:/Modelos/faster-whisper-small", "confirm_license": true }`; retorna metadados com status 201. A origem passa pela política `client_path` (caminho local absoluto, sem UNC/ADS/controles). Falha de validação/cópia retorna 400; instalação existente retorna 409 e nunca é sobrescrita.
- `DELETE /v1/transcription/models/small?confirm=true`: remoção explicitamente confirmada, sem corpo; retorna `{ "model": "small", "removed": true }`. Sem confirmação retorna 400; tarefa ativa/na fila, legado não gerenciado ou arquivos extras na instalação retornam 409. A origem nunca é apagada.

Arquivos obrigatórios: `model.bin` (1 MiB a 16 GiB), `config.json`, `tokenizer.json` e `vocabulary.txt` (não vazios, até 16 MiB cada). JSON deve ser um objeto válido. São copiados também, quando presentes, `README.md`, `model-card.md`, `LICENSE`, `LICENSE.txt`, `preprocessor_config.json` e `tokenizer_config.json`, com o mesmo limite de 16 MiB. Arquivos adicionais são ignorados; links de arquivos são recusados. O limite mínimo não comprova que o binário é um modelo legítimo, nem que corresponde ao nome selecionado: o operador escolhe a variante correta e fornece uma origem confiável. O importador não carrega o motor ASR para validar os pesos.

A cópia usa staging dentro de `HORUS_DATA_DIR/models`, hashes SHA-256 e flush dos arquivos; só depois de concluir e validar a cópia há rename para `models/<model>`. Falha remove o staging desta tentativa, sem publicar instalação parcial nem alterar a origem. Modelos locais/caches anteriores continuam listados quando reconhecidos, mas não podem ser apagados pelo importador. O destino não segue links para fora da raiz de modelos.

A resolução e validação do modelo usam `lstat`, sem seguir symlinks/junctions nos arquivos, pasta do modelo ou seus ancestrais. Caches Hub cujo snapshot contém links para blobs precisam ser materializados como uma pasta de arquivos regulares pelo operador antes do uso; o Hórus não segue esses links automaticamente. Diagnósticos de transcrição, alinhamento e runtime CUDA mostram nomes finais de arquivo em vez de caminhos absolutos; o texto reconhecido não é alterado. Caminhos estruturados de configuração, payload e manifesto local mantêm seu significado operacional e não são mensagens de erro.

`horus-model.json` registra arquivos, tamanhos, hashes, data, caminho local da origem e licença. MIT é a licença upstream declarada para Whisper; sem declaração local reconhecida, o status é `declared_unverified`. Model card com front matter `license: mit` ou arquivo LICENSE MIT resulta em `local_declaration`, que registra uma declaração local e não autentica a distribuição. Declaração conflitante, ambígua ou LICENSE não reconhecida é recusada. Isso não escolhe a licença do projeto Hórus nem substitui a avaliação da origem feita pelo operador.

A raiz externa `HORUS_WHISPER_MODELS_DIR`, se configurada, continua tendo prioridade na transcrição; importar para o Hórus não altera essa configuração. Para usar a instalação gerenciada, o operador precisa deixar de selecionar uma raiz externa diferente. Nenhuma configuração global, autenticação ou dado operacional é migrado.

Testes de fixture: `python -m pytest backend/tests/test_whisper_models.py -q`; snapshot aditivo aprovado pelo coordenador em conjunto com as rotas. Os testes usam pesos sintéticos de 1 MiB em pasta temporária, sem rede, modelo real ou inferência. A homologação de modelos reais, instalação NSIS/rollback e painel de prontidão permanecem fora deste incremento.
