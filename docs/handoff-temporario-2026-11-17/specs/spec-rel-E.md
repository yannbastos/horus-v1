CONTRATOS FIXOS (compartilhados; não os altere sem avisar no relatório):
- Canais: `test` e `production` (separados: bucket R2, namespace KV, chave de assinatura, rota).
- Layout no R2: `<channel>/releases/<version>/HORUS_<version>_x64-setup.exe`, `.../HORUS_<version>_x64-setup.exe.sig`, `.../release.json` (versão, sha256, tamanho, notas, pub_date, commit); `<channel>/latest.json` = manifesto do updater Tauri v2 (`version`, `notes`, `pub_date`, `platforms."windows-x86_64".{signature,url}`) **escrito POR ÚLTIMO** (um único PUT atômico) e só depois de validar os artefatos.
- Worker (workers.dev, HTTPS): `GET /<channel>/latest.json` e `GET /<channel>/releases/<version>/<arquivo>` exigem `Authorization: Bearer <token de instalação>`; sem token válido/revogado → 401/403 sem vazar existência. URL difícil de adivinhar NÃO é autenticação.
- Token por instalação: segredo aleatório de 256 bits mostrado UMA vez ao emitir; o Worker guarda só o hash (SHA-256) em KV com rótulo, canal, criação e flag de revogação; revogar = invalidar no KV (efeito imediato); a emissão/revogação é feita pelo admin com a credencial dele (wrangler/CI), NUNCA pelo app. O app guarda o token no cofre do Windows (keyring), nunca em arquivo/log, e o envia como cabeçalho `Authorization` na verificação e no download.
- App: endpoint e chave pública do updater vêm do overlay de build (`HORUS_UPDATE_BASE_URL`, `HORUS_UPDATE_CHANNEL`, `HORUS_UPDATER_PUBKEY`); HTTPS obrigatório (loopback só em builds de ensaio). Política mantida: detecção automática, instalação SÓ após confirmação humana; nunca durante produção/operação crítica.
- Versionamento: SemVer; produção = tag `vX.Y.Z`; teste = tag pré-release `vX.Y.Z-test.N`; a tag deve ser igual a `version` em `frontend/src-tauri/tauri.conf.json`, `frontend/package.json` e `frontend/src-tauri/Cargo.toml`; sem bump automático; publicação duplicada ou regressiva é recusada.
- Assinatura do updater (minisign via `tauri signer`) ≠ Authenticode. Chave de PRODUÇÃO: NÃO gerar nem armazenar (aguarda aprovação do usuário da custódia); canal `test` usa uma chave de TESTE separada.
